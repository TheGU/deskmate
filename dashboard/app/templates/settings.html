Backup

One file with everything: identity, settings, pushed data, telemetry.

The backup holds the session secret, every secret hash and any Home Assistant token. Treat the file like the token itself. It does not include DATA_DIR/modules.

Restore

Replace this hub's database with a backup from this build or an older one.

The token and the device key become the backup's. If the backup's device key is not the one the panel was flashed with, the device stops fetching until its Hub key is updated on the device's own web page, or by a reflash on firmware older than that field.
Every browser session ends, this one included: the session secret is the backup's too. You land on the sign-in page and need the backup's token.

Danger zone

Rotate the secrets: a new bearer token, a new device key, a new session secret.

Both new secrets are shown once and cannot be recovered. The flashed device stops fetching until its Hub key is set to the new device key, and every browser session ends.

Reset

To wipe this hub and start over: stop the container, delete data/deskmate.sqlite, start it again and open /setup. That throws away the identity, the settings, the pushed data and the telemetry history.
